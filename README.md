# PDF Converter

複数の画像を1つのPDFにまとめるブラウザ向けツール。

https://imaoki.github.io/pdf-converter/

インストールは不要で、画像はブラウザ内で処理されるだけです。どこかへ送信されることはありません。

## 機能

- **画像の読み込みと並べ替え**

    ドラッグ&ドロップ、フォルダごとの追加に対応。画像の並べ替え、回転、自然順ソートが可能。EXIFのOrientationは読み取って自動で補正。

- **ページ設定**

    用紙サイズ、向き、画像の収め方、余白、背景色を指定。画像そのものの大きさを用紙にすることも可能。

- **画質と容量**

    JPEG品質、解像度と長辺の上限、再圧縮の有無を指定。JPEGは再圧縮せずそのまま埋め込むため、既定では画質が劣化しません。EXIFやXMPなどのメタデータは除去。

- **しおり（アウトライン）**

    フォルダ名とファイル名からPDFのしおりを生成。フォルダの有無と拡張子の有無を切り替え可能。

- **分割出力**

    ページ数、容量、フォルダ、または任意の位置でPDFを分割し、ZIPでまとめて出力。

- **文書情報とページレイアウト**

    タイトル、作成者、件名、キーワード、作成日時の記録を指定。ビューアに伝える表示方法と右綴じの指定にも対応し、見開きの並びはツール上でも確認可能。

## 使い方

- 上記のURLをブラウザで開くか、最新リリースの`pdf-converter-<version>.html`をダウンロードしてブラウザで開いてください。`file://`のままで動作します。

- その他、本ツール特有の機能に関する詳細は **?** ボタンから確認できます。

## 依存しているもの

ありません。外部ライブラリの読み込みも、そのための通信も行いません。

## 動作確認

- Chrome、Firefox、Edge
- 入力はJPEG、PNG、BMP、WebP、GIF、AVIF
- 出力はPDF 1.7
