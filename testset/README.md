# 画像 → PDF 検証用画像セット

フェーズ2（画質・容量）の確認用に生成した画像です。すべて合成画像なので、
自由に配布・改変できます。

共通の目印として、多くの画像には次を入れてあります。

- 左上が赤、右上が青、左下が緑
- 上辺に太い黒線と「TOP」の文字

向きが正しければ赤が左上に来ます。回転や反転が起きると目印の位置で判別できます。

## EXIF の向き

| ファイル                             | 内容                                                 |
| ------------------------------------ | ---------------------------------------------------- |
| `exif-orientation-1.jpg` 〜 `-8.jpg` | 600 × 400 の同じ画像に Orientation 1〜8 を付けたもの |

1 は無変換、3 は180度、6 は時計回り90度、8 は反時計回り90度。
2・4・5・7 は反転を含むため、鏡像になっていないかの確認に使います。
5〜8 は表示上 400 × 600 の縦長になります。

## メタデータ

| ファイル                    | 内容                                                             |
| --------------------------- | ---------------------------------------------------------------- |
| `meta-gps-exif.jpg`         | GPS座標、撮影日時、カメラ名、説明文を含む 1600 × 1200            |
| `meta-gps-orientation6.jpg` | 上記に加えて Orientation 6。向き補正とメタデータ除去の両立を確認 |

除去後は、出力PDFから取り出したJPEGに `Exif` セグメントが残っていないことを確認します。
`meta-gps-orientation6.jpg` は、EXIFを消しても向きが正しいままであることの確認用です。

## JPEG の種類

| ファイル               | 内容                                                                    |
| ---------------------- | ----------------------------------------------------------------------- |
| `jpeg-progressive.jpg` | プログレッシブJPEG                                                      |
| `jpeg-cmyk.jpg`        | CMYK（Adobe APP14 付き）                                                |
| `jpeg-grayscale.jpg`   | グレースケール 1成分                                                    |
| `jpeg-q100-444.jpg`    | 品質100・サブサンプリングなし。再圧縮での劣化とサイズ変化が分かりやすい |
| `jpeg-q30.jpg`         | 品質30。すでに劣化した画像を再圧縮したときの挙動                        |

## PNG とその他の形式

| ファイル                   | 内容                                                  |
| -------------------------- | ----------------------------------------------------- |
| `png-alpha.png`            | 半透明の階調を含む RGBA                               |
| `png-palette-alpha.png`    | パレット形式                                          |
| `png-interlaced.png`       | インターレース                                        |
| `png-photo.png`            | 写真的な内容のPNG。可逆のままだとPDFが大きくなる例    |
| `png-screenshot.png`       | 細い線と文字。再圧縮の劣化が最も目立つ                |
| `bmp-24bit.bmp`            | 24bit BMP                                             |
| `webp-lossy.webp`          | 非可逆WebP                                            |
| `webp-alpha-lossless.webp` | 可逆WebP・透過あり                                    |
| `avif-lossy.avif`          | AVIF                                                  |
| `gif-animated.gif`         | 3フレームのアニメーション。先頭フレームだけが使われる |

## 極端なサイズ

| ファイル                        | 画素数              | 確認したいこと                       |
| ------------------------------- | ------------------- | ------------------------------------ |
| `size-tiny-16px.png`            | 16 × 16             | 拡大の挙動と「縮小のみ」の効き       |
| `size-panorama-6000x200.jpg`    | 30:1 の横長         | 用紙への収まりと向きの自動判定       |
| `size-tall-200x6000.jpg`        | 1:30 の縦長         | 同上                                 |
| `size-huge-9000x6750.jpg`       | 60.8 MP             | 縮小なしで通るか。処理時間           |
| `size-over16384-17000x3400.jpg` | 長辺が16384を超える | Canvasの寸法上限。縮小を挟めば通るか |

最後の2つはブラウザによって結果が変わります。Chrome、Firefox の両方で確認してください。
